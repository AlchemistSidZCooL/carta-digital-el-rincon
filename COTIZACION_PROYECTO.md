**Desarrollador:** Daniel (Danisid)

---

## 1. Diseño y Arquitectura Frontend (UX/UI)
- Diseño conceptual "Alta Costura" (Dark Theme, tipografías modernas, Glassmorphism).
- Arquitectura SPA (Single Page Application) Mobile-First responsiva (adaptable a PC/Tablets).
- Componentes interactivos con animaciones fluidas (Hover effects, sticky headers).
- **Valor estimado de mercado:** 550,00 €

## 2. Desarrollo Web (React + TypeScript + Vite)
- Programación modular orientada a componentes.
- Creación de base de datos local JSON (`productos.json`) para gestión y escalabilidad del menú.
- Integración de sistema de Progressive Web App (PWA) para instalación nativa en móviles.
- **Valor estimado de mercado:** 750,00 €

## 3. Dirección de Arte e IA Gastronómica
- Prompt Engineering para generación de 25+ fotografías de platillos hiperrealistas y de alta gastronomía.
- Curaduría visual, unificación de estilos (iluminación dramática, fondos rústicos/madera).
- Optimización masiva de assets (conversión a WebP, redimensionamiento para carga ultrarrápida).
- **Valor estimado de mercado:** 400,00 €

## 4. Infraestructura, Despliegue y Redes (DevOps)
- Configuración de integración continua (CI/CD) vía GitHub y Netlify.
- Gestión y configuración de DNS en Cloudflare.
- Aprovisionamiento de Certificados de Seguridad (SSL/HTTPS).
- **Valor estimado de mercado:** 200,00 €

## 5. Accesibilidad y Herramientas a Medida
- Desarrollo de script personalizado en Python para generación de Código QR de alta resolución.
- Incrustación de logotipo y configuración de alta tolerancia a errores de lectura.
- **Valor estimado de mercado:** 100,00 €

## 6. SEO Técnico y Posicionamiento Web
- Metadatos, canonical, Open Graph y Twitter Card con imagen social 1200x630.
- Datos estructurados JSON-LD (`Restaurant`, `Menu`, `FAQPage`, `WebSite`), generados en cada build.
- Contenido pre-renderizado en el HTML, `sitemap.xml`, `robots.txt`, sección «Cómo llegar» con mapa y FAQ.
- Integración de Google Tag Manager y optimización de rendimiento (WebP, caché).
- **Valor estimado de mercado:** 250,00 €

### Servicio adicional (no incluido): Perfil de Empresa de Google
- Alta, verificación y optimización de la ficha local (horario, fotos, web, categorías) y enlace con el JSON-LD.
